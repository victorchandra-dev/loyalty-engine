# LoyaltyFlow restart plan (Tue 29 Sep – Fri 2 Oct 2026)

**Goal:** by Friday, LoyaltyFlow runs on the Amada Flow store as a private app
hosted on Cloud Run, with the bugs that lose points or money fixed.

**Background:** bugs 1–5 come from
`amadaflow.com/claudedocs/analysis_loyaltyflow_2026-09-29.md`. Bugs 6–11 were
found in a code read on 2026-09-29.

## Decisions (confirmed by the owner on Wed 30 Sep)

| Decision | Choice |
|---|---|
| App Store | No. This is a private app for Amada Flow only |
| Infrastructure | **Everything the engine runs on is in GCP:** Cloud Run, Cloud SQL Postgres, Secret Manager, Cloud Logging and Error Reporting. Supabase isn't used for the engine; the storefront keeps using it for its own features. |
| What Friday means | Soft launch: the app runs on the live store, the storefront stays `coming_soon`, and staff place test orders. Open to customers on Monday |
| Existing customers | Start at 0 points, with their tier set from lifetime spend |
| Move metaobject definitions into the TOML | Skip |

Things that stay outside GCP by design: the storefront runs on Shopify
Oxygen, and points and program data live in Shopify metafields and
metaobjects. The database only holds login sessions and the processed-webhook
keys. Nothing in it is irreplaceable: losing it means the admin logs in again.

## Thu 1 Oct, evening: Shopify Plus blocker and the new plan

Installed on the live store (`76352b-84.myshopify.com`) with the custom
install link. Shopify created the session at 11:11 UTC. "Sync program" then
failed with: *"Shop must be on a Shopify Plus plan to activate functions from a
custom app."* Shopify's docs say only Plus stores can use custom apps that
contain Shopify Functions. Development stores are exempt, which is why the
test store worked. The live store isn't on Plus.

- **Still works without the Function:** earning points (orders, signup,
  referral), refunds taking points back, balances and tiers on the
  storefront. The live store already has loyalty tiers and rules, so Sync
  resolved a program and only failed at the discount step.
- **Doesn't work:** tier % discounts and redeemed rewards at checkout.
- **The program is paused on the live store** (the owner paused it).

**Decision (owner, 1 Oct): points first.** Friday: earning only, tested
through the preview. Friday to Monday: replace the Function with Shopify's
built-in discounts, which work on every plan:
- **Tiers:** one automatic % discount per tier, limited to a customer segment
  such as `amount_spent >= 700` (`discountAutomaticBasicCreate` with
  `context.customerSegments`).
- **Rewards:** on redeem, create a discount code for that one customer
  (`discountCodeBasicCreate` with `context.customers`, usage limit 1, expires
  in 30 days). The storefront applies it to the cart and shows the code.
  Shopify enforces single use, so the reward metafield bookkeeping goes away.
- Delete the `loyalty-discount` Function extension and the code that
  maintains the automatic app discount.
- **Owner decisions (1 Oct):** a reward code and the tier discount **stack**:
  both are order discounts with `combinesWith.orderDiscounts = true`. Rewards
  are **added to the cart automatically** by the storefront, with the code
  also shown on `/account/loyalty`.

Open to customers once rewards pass in the preview (Tuesday at the latest).
